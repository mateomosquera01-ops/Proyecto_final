# Proyecto_final
Se establece un caso de estudio en el que se crea una página web dedicada a la venta de productos textiles haciendo uso de google IA studio, haciendo parte backend con postgresSQL y un front end javascript, typescript y HTML 

# página web full stack Tec.tex

la págia web tiene el objetivo de brindar información de productos y consultorías de empresas

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript ES6+
- Google AI Studio / Gemini
- Git y GitHub
- PostgresSQL
- Netlify
- Supabase
- n8n

## Metodología de desarrollo

1. Planeación y definición del problema.
2. Investigación y diseño de la solución.
3. Desarrollo asistido por inteligencia artificial.
4. informe de auditoría crítica del código generado por IA
5. Publicación y documentación.
## Roadmap del proyecto
- Análisis y definición de requerimientos.
- Diseño de arquitectura.
- Diseño de interfaz UI/UX.
- Modelado de base de datos.
- Configuración inicial de Supabase.
- Desarrollo de página principal.
- Desarrollo del catálogo.
- Pruebas funcionales y de seguridad.
- Despliegue en Netlify.
## Personalización

1. Clonar el repositorio.
2. Abrir el proyecto en Visual Studio Code.
3. Modificar el contenido de index.html.
4. Personalizar los estilos en css/styles.css.
5. Ajustar las funcionalidades en js/script.js.
