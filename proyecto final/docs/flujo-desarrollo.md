
# Flujo de Trabajo - Proyecto Final

## 1. Planeación y análisis
- Definir el objetivo del proyecto.
- Identificar las necesidades de los usuarios.
- Establecer los requerimientos funcionales y no funcionales.
- Definir las tecnologías de desarrollo.
- Organizar las actividades mediante GitHub Projects.

## 2. Diseño y arquitectura
- Diseñar la interfaz de usuario.
- Definir la estructura del frontend.
- Planificar la arquitectura del backend.
- Diseñar el modelo entidad-relación de la base de datos.
- Establecer la comunicación mediante una API REST.

## 3. Desarrollo del frontend
- Crear la estructura HTML5.
- Implementar estilos CSS3.
- Desarrollar funcionalidades con JavaScript ES6+.
- Crear formularios y elementos interactivos.
- Implementar diseño responsive.
- Preparar la integración con el backend.

## 4. Desarrollo del backend
- Configurar el entorno del servidor.
- Implementar la lógica de negocio.
- Crear endpoints de la API.
- Implementar validaciones.
- Gestionar solicitudes y respuestas HTTP.
- Configurar el manejo de errores.

## 5. Diseño e implementación de la base de datos
- Identificar las entidades y atributos.
- Definir tablas y relaciones.
- Establecer claves primarias y foráneas.
- Configurar la conexión entre backend y base de datos.
- Implementar operaciones CRUD.

## 6. Integración de componentes
- Conectar el frontend con el backend.
- Enviar información mediante solicitudes HTTP.
- Recuperar información desde la base de datos.
- Mostrar datos dinámicos en la interfaz.
- Implementar mensajes de confirmación y error.
- Validar el intercambio de información.

## 7. Pruebas y optimización
- Realizar pruebas funcionales.
- Verificar formularios y navegación.
- Comprobar las operaciones CRUD.
- Validar la comunicación entre frontend y backend.
- Corregir errores.
- Optimizar rendimiento y accesibilidad.

## 8. Control de versiones
- Registrar avances mediante commits.
- Utilizar ramas cuando sea necesario.
- Documentar problemas mediante Issues.
- Actualizar el tablero Kanban.
- Mantener el repositorio organizado.

## 9. Despliegue y publicación
- Preparar el frontend para producción.
- Publicar la landing page en GitHub Pages.
- Configurar el alojamiento del backend.
- Configurar el alojamiento de la base de datos.
- Verificar la comunicación entre los servicios publicados.

## 10. Documentación y evaluación final
- Actualizar el README.md.
- Documentar las tecnologías utilizadas.
- Registrar las decisiones técnicas.
- Verificar el historial de commits.
- Comprobar los Issues y el tablero Kanban.
- Elaborar el documento PDF de reflexión.

---

## Consideraciones técnicas

El proyecto se desarrollará de forma incremental,
permitiendo realizar ajustes durante cada etapa.

La integración entre frontend, backend y base de datos
se implementará progresivamente según la arquitectura
y las tecnologías seleccionadas.

Git y GitHub se utilizarán para mantener el control
de versiones y documentar la evolución del proyecto.
